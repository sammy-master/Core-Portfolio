# SAKSHAM SHARMA // THE CORE — Interactive WebGL Mission Portfolio

An interactive 3D WebGL mission-based developer portfolio built from scratch with **Three.js**, **custom GLSL shaders**, **post-processing bloom + chromatic warp**, **procedural Web Audio synthesis**, and **10 fast-paced 5–10 second micro-missions**.

---

## ✨ Architecture & Highlights

- **Living Crystalline Core (GLSL Shader)**: An iridescent, simplex-noise displaced icosahedron at the center of an interactive 3D orrery. Every mission cleared forges new orbiting skill shards around the Core.
- **Particle Name Boot Sequence**: Thousands of GPU point-cloud particles form `SAKSHAM SHARMA`, repel from your cursor in real time, and explode into hyperspace warp on entry.
- **10 Playable Micro-Missions (5–10s each)**:
  1. `01 · Hello, World` (`type.js`) — Type `printf("hi");` on glowing 3D holographic key-tiles.
  2. `02 · Sort It Out` (`sort.js`) — Swap 3D neon bars in ascending order (DSA & C++).
  3. `03 · Bug Hunt` (`bugs.js`) — Squash 6 scurrying low-poly bugs on a live code backdrop (Python & Automation).
  4. `04 · Spot the Phish` (`phish.js`) — Inspect holographic URL cards and shatter the phishing domains (Cybersecurity & PhishGuard).
  5. `05 · Assemble the Web` (`assemble.js`) — Drag `<html>`, `<css>`, and `<js>` blocks into their blueprint sockets (Full-Stack Web).
  6. `06 · Tune the Vibe` (`tune.js`) — Match the target orb's HSL color harmonic on a live 2D shader palette (UI/UX & Design).
  7. `07 · Ship It` (`launch.js`) — Hit the green zone 3 times (`git add`, `git commit`, `git push`) to launch the rocket (Git, Vercel & DBMS).
  8. `08 · Chat Raid` (`chat.js`) — Reply to community messages while avoiding red spam traps (Discord Community & Bots).
  9. `09 · Tensor Time` (`tensor.js`) — Solve 2×2 holographic matrix dot-products with animated data-flow particles (AMD ROCm GPU & Quantum).
  10. `10 · Hackathon Boss` (`boss.js`) — Pilot a sleek ship, dodge falling `DEADLINE` hazards, and collect `IDEA` sparks for 10 seconds (Bosch Internship & Smart India Hackathon 2026).
- **Zero External Audio Files**: Every click, chord pad, warp whoosh, and victory arpeggio is synthesized live using the Web Audio API.
- **Instant Recruiter View**: One-click accessible view for recruiters in a hurry, plus **Player Card** (interactive SVG skill radar), **Project Vault** (3D holographic tilt cartridges), and **Konami Code God Mode** (`↑↑↓↓←→←→BA`).
